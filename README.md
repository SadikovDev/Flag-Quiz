# Country Flags Quiz Game

Hello everyone! I’m excited to share my first full-scale project built with **Unity** and **C#**.

## About the Game
It's a casual flag-guessing game where you can:
* Guess country flags and earn coins.
* Unlock new background themes.
* Purchase extra time to keep your streak going.

The gameplay is short but engaging, perfect for a quick **5 to 15-minute** session!

## Current Status & Development
* **Localization:** Fully available in Russian, with partial English support (completely playable!).
* **Development Note:** I didn't write 100% of the code from scratch. I used Google Gemini to help me implement two complex methods. 

I hope you find it interesting and have fun playing!
